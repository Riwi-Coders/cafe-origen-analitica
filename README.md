# Café Origen - Analítica

Proyecto desarrollado durante la Sesión 4 de RIWI, enfocado en la resolución de problemas con arreglos y objetos en JavaScript.

## Objetivo

Construir un motor básico de analítica que permita analizar el historial de ventas de Café Origen y responder preguntas de negocio.

## Tecnologías

- JavaScript
- Node.js
- Git y GitHub

## Estructura del proyecto

- `src/datos.js`: contiene el historial de las 12 ventas.
- `src/explorar.js`: permite explorar los registros mediante la consola.
- `src/analitica.js`: contendrá las funciones de análisis.
- `bitacora.md`: documenta el análisis de los datos, las pruebas y las decisiones tomadas.

## Ejecución

Desde la raíz del proyecto, ejecutar:

```bash
node src/explorar.js
```

Este comando muestra la cantidad de registros, el primero, el último, un producto específico y la tabla completa de ventas.
